# CORDA Democratic AI-Readiness Index — Interactive Dashboard

Interactive dashboard measuring AI-governance readiness and democratic backsliding risk across 27 countries.

**Built by CORDA Democracy Fellows — Coleman Snell, Jason Hung, Casimir Wypyski, Eilaf Mohamed**

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Hosted on Hugging Face Spaces (Static). See `CORDA_DASHBOARD_SPEC.md` Section 8 for deployment instructions.
